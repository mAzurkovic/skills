# Schematic rules

What a senior EE checks before signing a schematic. Each rule is checkable: apply it, record the evidence.

## Part selection

### Ratings and derating
- Capacitors, ceramic: rated voltage ≥ 2× working voltage on bus/power rails, ≥ 1.5× on logic rails. 48 V bus (52 V max) → 100 V parts.
- Capacitors, ceramic DC bias: X7R/X5R lose capacitance under bias. Check the manufacturer's DC-bias curve for every cap where the value matters (bulk, charge pump, regulator in/out). Record effective capacitance at working voltage. Size up the package or value until the effective value meets the datasheet requirement.
- Capacitors, polymer/electrolytic: rated voltage ≥ 1.2× max working, ripple current rating ≥ calculated ripple with margin. Record both numbers.
- Resistors: dissipation ≤ 50 % of rating at worst case. Check working-voltage rating where a resistor sees bus voltage (0402 ≈ 50 V, 0603 ≈ 75 V, 0805 ≈ 150 V): divider top resistors on a 52 V bus are 0603 or larger.
- MOSFETs: VDS ≥ 1.5× max bus (ringing). Check SOA, Qg against driver budget, Rds(on) at the actual gate voltage, not 10 V, when the bus can be low.
- Diodes: VR ≥ 1.5× max reverse, IF ≥ 2× average.
- Every IC: max supply ≥ worst-case rail incl. transients; record margin.
- Temperature: every part rated for the board's ambient + self-heating (≥ 85 °C; ≥ 105 °C near the power stage).

### Dielectric and type
- C0G/NP0: crystal load caps, timing, filters, anything where the value sets a frequency or time constant.
- X7R (X5R only on cool low-voltage rails): decoupling and bulk.
- Never Y5V/Z5U.
- Resistors: 1 % default. Feedback dividers, current-set, ADC dividers: 1 % or better, thin film if tempco matters.

### Sourcing and BOM hygiene
- Every part has an LCSC number with stock ≥ 5× the build quantity.
- Prefer JLC basic parts for passives (no extended-part fee).
- Consolidate values: if 10 k and 10.2 k both work, use one. Fewer unique lines, fewer mistakes.
- No package smaller than 0402. No 0402 on nets above 25 V.

## Circuit practice

### Power
- Every IC power pin gets its own decoupling cap per the datasheet's recommendation (value, dielectric, count), plus the bulk cap it calls for. Draw the cap next to that pin.
- Every rail has a name with its voltage (`+3V3`, `+5V`, `VBUS`), never generic (`VCC`).
- Rails entering from a connector or generated by a non-power-output pin get a `PWR_FLAG`.
- Regulators: calculate output divider, timing resistor, inductor, cap values; write the formula and result as a text note on the sheet with the datasheet section.
- Reverse polarity, inrush, ESD, and fusing: follow the design doc. If it puts protection off-board, do not add parts; note it.

### Pins and logic
- No floating inputs. Every unused input pin: tie per datasheet (to GND, VDD, or via resistor). Every unused output or NC pin: explicit no-connect flag.
- Open-drain/open-collector outputs: pull-up present, value justified (rise time vs. current).
- Reset, enable, boot-mode pins: defined default state by a resistor, not by firmware.
- Pins with internal pull-ups/downs: note it on the sheet when you rely on it.
- 5 V-tolerant vs. not: any MCU pin driven from a higher rail is FT, checked against the MCU's pin table.
- MCU pin assignment exactly as the design doc's interface table.

### Analog and sensing
- ADC inputs: RC anti-alias filter at the pin, with τ consistent with the sample time; series R ≤ the MCU's max source impedance for the sample time.
- Current shunts: 4-terminal connection. Use a 4-pad shunt footprint or a net tie so the sense nets (`<phase>_SENSE_P/N`) are separate from the power nets in layout. Sense nets go straight to the amplifier pins with the filter the amp's datasheet recommends.
- Voltage dividers on high-voltage nets: show the full-scale calc as a note.

### Interfaces
- USB: ESD part at the connector, CC resistors for the role, D+/D− named `USB_DP`/`USB_DM` (layout uses the names for diff-pair rules).
- CAN: termination per design, `CAN_H`/`CAN_L` names.
- Every off-board signal: protection per the design doc.

### Test and debug
- Test points on every rail, every fault/status line, and the signals the design doc lists. Name them (`TP_3V3`).
- Programming/debug header pinout matches the programmer's.

### Net naming
- Every net that matters to layout has a name: power, phases (`PHASE_A`), gate drive (`GHA`, `SHA`, `GLA`, `SLA`), sense, clocks, diff pairs. Layout assigns netclasses by these names. Unnamed nets are only for trivial two-pin links.

## Drawing conventions

### Structure
- Root sheet: one hierarchical sheet symbol per block, connected by hierarchical pins. Reads as the block diagram.
- One sheet per functional block, e.g.: power input + bulk, logic power, MCU, gate driver, bridge + sense, encoder, comms + connectors.
- Paper A4 per sheet (A3 only for the bridge if needed). Fill it: a sheet with three parts in one corner is wrong size or wrong split.
- Title block on every sheet: project, sheet title, revision, date.

### Layout on the page
- Signal flow left to right: inputs on the left, outputs on the right.
- Higher voltages at the top, ground at the bottom. Rail symbols point up, GND symbols point down.
- Everything on the 1.27 mm grid; parts placed on 2.54 mm.
- Group parts by function with space between groups. Decoupling caps beside the pin they serve.

### Wires and labels
- Never put a label or power symbol directly on an IC pin. Draw a 2.54 mm wire stub, then the label. Pin numbers must stay readable.
- Every T gets a junction dot. No 4-way junctions: offset into two Ts.
- Wires never pass through a symbol body or over text.
- Crossing wires: avoid; when unavoidable, cross at 90° with no dot.
- Long runs across the sheet: replace with net labels at both ends.
- Local labels for nets within a sheet, hierarchical labels for nets crossing sheets, power symbols for rails. No global labels for signals.
- No dangling wire ends.

### Text
- Reference and value visible on every part, not overlapping anything.
- Capacitor values include voltage and dielectric (`100n 50V X7R`), resistors include power when > 0.1 W.
- Text notes for: design calcs, datasheet references, DNP/assembly notes, "do not change" constraints.
- Annotate references last, sheet by sheet, so U1..Un follow the page order.
